# Fast Polynomials

Research sources, formalization, and the interactive companion for
*Fast Evaluation of Polynomials with Rational Preprocessing*.

- `main.tex`, `header.tex`, `sections/`, `references.bib` — paper sources
- `FastPoly.lean`, `FastPoly/`, `lakefile.lean` — Lean formalization and build
- `tools/` — reference compiler and decoder, benchmark generators, and the
  paper's benchmark sources under `tools/bench/`
- `website/` — dependency-free interactive polynomial-chain compiler

The website is published at <https://thomasahle.com/fast-polynomials/>.
See `website/README.md` for local preview and test instructions.
