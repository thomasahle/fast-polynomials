# adversarial experiments: scan (threads=12, log2 trials=29 for heuristic hashes, 27 for proven ones)

## Differential site scan, 32-byte messages (4 words w0..w3)

Base message: fixed pseudo-random 32 bytes.  The second message applies the listed differential(s):
'xor M' complements the word (XOR with 2^64-1); 'add A' adds 0x5555...5 mod 2^64; 'add -A' subtracts it.
For the paper's recurrence the words are (a1,b1,a2,b2) = (w0,w1,w2,w3); the step-2 multiplication
has multiplicands (b2 + x^3) and (P1 + x^2) with P1 = a1 + ..., so the pair (w0,w3) is its (delta,eps) site.
Entries: collisions / trials over random seeds (random secret where applicable).
